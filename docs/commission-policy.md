# 2026 销售提成统一规则（应用基线）

版本 v2.0，2026-09-12 更新，自 2026-08-01 起按实际到账月份生效。金额单位为人民币元。

## 权威与结算口径

正式专项审批 > 本规则 > 配套 Excel > 历史文件、历史公式和业务台账备注。提成以实际到账为触发条件，结算月按到账日期。正常、待审批、待复核和一事一议分别汇总；只有正常记录进入正式发放。

## 反拆单与业务归类

先检查同客户、同项目背景、12 个月内的关联合同。证据充分时合并金额判断；只有名称或编号相似时人工复核。

以下任一条件转大客户/项目型：

- 年度合同金额或关联金额大于等于 300,000；
- 含定制化开发；
- 分阶段验收交付；
- SaaS 与定制组合。

合同金额大于等于 3,000,000 时总经理一事一议；没有专项方案不得自动输出正式提成。

## 回款时效

逾期天数 = 到账日 - 应收日。

| 逾期天数 | 系数 |
| --- | ---: |
| ≤5（含提前） | 1.00 |
| 6–30 | 0.90 |
| 31–90 | 0.70 |
| 91–180 | 0.50 |
| >180 | 0.00 |

经确认属于产研、交付、上线或其他非销售责任时按 1.00，但必须保留原因和审批依据。日期缺失时不得猜测。

## SaaS

### 基数

- 标准 SaaS 首年：本期回款 − 本期分摊实施费 − 本期分摊商务费。
- 标准 SaaS 续费：本期回款 × 50%，不再扣费。
- 私有云首年：本期回款 − 本期分摊实施费 − 本期分摊商务费。
- 私有云不设续费。
- 分期只扣本期有依据的费用分摊；未知分摊不得猜测。
- 基数小于 0 时按 0 预览并人工复核，不生成负提成。

### 档位

| 基数 | 自拓 | 线索 | 转介绍 |
| --- | ---: | ---: | ---: |
| ≤50,000 | 10% | 8% | 10% |
| >50,000 且 ≤100,000 | 12% | 9% | 11% |
| >100,000 且 <300,000 | 15% | 10% | 12% |

公式：基数 × 比例 × 时效系数。SaaS 销售本人 100%，主管池 0。

### 分期与统一计提

- 默认每期独立判断档位，不回溯补差。
- 合同或审批在任何一期发放前明确选择全额到账统一计提时，可按首年总基数判断统一档位。
- 各期时效系数相同时，可在全额到账后用总基数一次计算。
- 各期时效系数不同时，先以首年总基数确定统一比例，再计算各期基数 × 统一比例 × 各期时效系数之和。
- 任何一期已正式发放后，不得改为整单档位追溯补差。
- 签约 12 个月后仍未支付的尾款不再计提。

## 大客户 / 项目型

### 累计分段

| 累计基数分段 | 自拓 | 线索 | 转介绍 |
| --- | ---: | ---: | ---: |
| 0–50,000 | 10% | 8% | 10% |
| 50,000–300,000 | 12% | 9% | 11% |
| 300,000–1,000,000 | 7% | 6% | 7% |
| 1,000,000–3,000,000 | 4% | 3.5% | 4% |

### 折扣

成交折扣 = 合同金额 ÷ 原始报价。

| 成交折扣 | 系数 | 审批 |
| --- | ---: | --- |
| ≥80% | 1.00 | 无特殊审批 |
| 70%–80% | 0.80 | 销售总监 |
| 60%–70% | 0.70 | 总经理 |
| 50%–60% | 0.60 | 总经理 |
| <50% | 向上取整到下一 10% | 总经理 |

报价缺失时系数按 1 计算预览，但状态为待复核，不进入正常发放。里程碑基数 = 实际回款 × 折扣系数。

### 里程碑差额法

使用合同真实里程碑；里程碑条件完成且回款到账后才触发。

```text
累计后 = 累计前 + 本里程碑基数
基础提成 = 分段提成(累计后) - 分段提成(累计前)
```

不得每期从 0 重算或使用整单平均费率。

### 特殊系数与团队分成

- 主动提前回款至少 60 天，或交付提前至少 30 天，对应里程碑系数 1.05；两项不叠加。
- 缺少证据时不得应用 1.05。
- 默认销售 90%、主管池 10%；特殊比例必须有明确审批和适用范围。
- 提成总额 = 基础提成 × 时效系数 × 特殊系数。

## 状态优先级

1. 总经理一事一议；
2. 转大客户/项目型；
3. 不计提；
4. 待审批；
5. 待复核；
6. 正常。

只有状态“正常”的销售应发和主管池金额进入正式发放。
