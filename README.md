# 佣金台账

面向财务人员的月度销售提成结算应用。系统录入合同、分期付款和实际回款，按 2026 统一销售提成规则计算销售本人应发、主管池、待审批预览和待复核预览，并自动生成可复制给销售人员的结算说明。

## 已实现功能

- 录入客户、合同名称与编号、业务类型、交付要求、客户来源和销售人员。
- 录入任意多期付款计划、应收日、实际到账日、到账金额和费用分摊。
- 业绩计提月份默认当前月份，也可手动修改；以实际到账日期筛选。
- 支持标准 SaaS 首年、SaaS 续费、私有云首年和定制/大客户项目。
- 按销售人员汇总当月正常应发，并将待审批、待复核、一事一议等状态隔离。
- 自动生成逐笔计算方式说明，一键复制后可直接发送给销售人员。
- 合同与分期记录使用 Cloudflare D1 持久化。
- 空台账展示明确标注的演示数据；保存第一份真实合同后自动退出演示模式。

## 规则边界

应用基于《2026 销售提成统一规则》v2.0（2026-09-12）实现。正式专项审批高于统一规则；只有状态为“正常”的销售应发与主管池金额进入正式发放。缺少到账日期、应收日期、报价、关联合同检查或必要审批依据时，系统不会猜测，而是标记待复核、待审批或一事一议。

详细政策见 [docs/commission-policy.md](docs/commission-policy.md)。

## 本地运行

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:3000`。本地 D1 数据保存在项目的 Wrangler 状态目录中。

## 校验

```bash
npm test
npm run lint
npm run build
```

测试用例覆盖原 Skill 确定性引擎中的 10 项政策控制，包括 SaaS 档位、续费折半、分期/统一计提、项目累计分段、折扣审批和 300 万以上一事一议。

## 数据库

数据库结构位于 `db/schema.ts`，生成的迁移位于 `drizzle/`。站点配置已声明 D1 绑定 `DB`。

```bash
npm run db:generate
```

部署时可设置 `SITE_URL`，用于生成正确的 Open Graph 分享图片地址。
